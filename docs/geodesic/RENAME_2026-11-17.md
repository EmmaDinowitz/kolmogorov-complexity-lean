# Namespace move of the interface extensions (2026-11-17)

Step 5a of the GeodesicSurfaces reorganization (owner decision O5): the package
`GeodesicInterface` moved its declarations (`FlowData`, `LeafKind`, `FlowBox`,
`GeodesicReconstructionData`, `CurvatureFlow` and everything under them) from the namespace
`Kolmogorov.PointToSet` to the namespace `GeodesicInterface`. The Geodesic chapter of this
library extends `FlowData` and `GeodesicReconstructionData` with its own declarations; those
blocks now sit in `namespace GeodesicInterface.FlowData` and
`namespace GeodesicInterface.GeodesicReconstructionData`, so that dot notation (`D.foo`,
`G.foo`) keeps working. The short names are unchanged; only the namespace prefix moved.

Everything else of the chapter (`EffectiveGeodesicData`, `OrbitDatum`,
`OrbitToLocationEstimate`, the theorems on `orbitComplexityNat` and `centeredBSCost`, the upper
bound) stays in `Kolmogorov.PointToSet`, whose sections now `open GeodesicInterface`. No
deprecated aliases are generated for the old names: an alias under
`Kolmogorov.PointToSet.GeodesicReconstructionData` would recreate the namespace the move
removes, and no module outside the chapter used them.

## Prefix map

- `Kolmogorov.PointToSet.FlowData.` → `GeodesicInterface.FlowData.`
- `Kolmogorov.PointToSet.GeodesicReconstructionData.` →
  `GeodesicInterface.GeodesicReconstructionData.`
